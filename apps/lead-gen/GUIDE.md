# B2B 获客自动化实战指南

## 🌍 针对不同国家的获客策略

### 越南 Vietnam

| 维度 | 详情 |
|-----|------|
| **首选渠道** | Zalo (70% 渗透率) > WhatsApp (45%) |
| **商业文化** | 正式但友好，喜欢称呼先生/女士 |
| **决策速度** | 中等，需要建立信任 |
| **价格敏感度** | 高，极度价格敏感 |
| **最佳联系时间** | 09:00-11:30, 14:00-17:00 |

**实战要点**：
1. **Zalo 是关键**：越南人更习惯用 Zalo，不是 WhatsApp
2. **直接报价**：越南客户喜欢直接看到价格
3. **样品策略**：免费样品是打开市场的关键
4. **语言**：使用越南语或简单的英语

**话术特点**：
- 使用 "anh/chị" 表示尊重
- 直接说明产品优势
- 结尾询问是否需要样品

## 📋 快速开始

### 1. 环境准备

```bash
cd /Users/mac/project/idea-turbo/apps/lead-gen
source venv/bin/activate
```

### 2. 导入数据

```bash
# 导入已抓取的越南数据
python automation_engine.py --import output/vietnam_leads.json --country vietnam

# 查看统计
python automation_engine.py --stats

# 查看今日待联系列表
python automation_engine.py --list
```

### 3. 生成联系清单

```bash
python pipeline.py generate --country vietnam
```

### 4. 手动发送（推荐初期）

从生成的清单中选择客户，手动通过 Zalo/WhatsApp 发送消息。

## ⚠️ 防封号策略

### 通用规则

| 规则 | 限制 |
|-----|------|
| 每账号每日发送 | ≤ 50 条 |
| 消息间隔 | 30-120 秒随机 |
| 新账号养号期 | 7 天 |
| 账号轮换 | 使用 2-3 个账号 |

### Zalo 特殊规则

- 新号每天只能加 20-30 人
- 群发需要官方账号 (OA) 权限
- 被举报 3 次即封号

### WhatsApp 特殊规则

- 新号前 7 天限制严格
- 使用 WhatsApp Business API 更安全
- 避免发送相同内容给多人

### Telegram 特殊规则

- Bot API 无每日限制
- 但避免被用户举报为垃圾信息
- 使用频道+群组组合策略
