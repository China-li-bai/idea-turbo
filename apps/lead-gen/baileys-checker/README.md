# Low Risk WhatsApp Checker

基于 Baileys 的低风险 WhatsApp 号码检测工具。

## ⚠️ 风险说明

**重要提示：** 此工具仅供学习和研究使用。使用此工具可能违反 WhatsApp 服务条款，可能导致账号被封。使用风险自负。

## 🛡️ 低风险策略

| 策略 | 说明 | 默认值 |
|-----|------|--------|
| **随机延迟** | 每次检测间的随机等待时间 | 8-20秒 |
| **批量限制** | 每次会话最多检测数量 | 15个 |
| **会话超时** | 最大会话时长 | 5分钟 |
| **分批处理** | 建议分多天完成检测 | - |

## 📦 安装

```bash
cd baileys-checker
npm install
```

## 🚀 使用

### 1. 运行检测

```bash
npm run check
# 或指定输入文件
node checker.js ../output/contacts.csv
```

### 2. 扫码登录

运行后会显示二维码，用 WhatsApp 扫描登录。

### 3. 查看结果

结果会保存到 `../output/whatsapp_results.csv`

## 🔧 配置

编辑 `checker.js` 中的 CONFIG 对象：

```javascript
const CONFIG = {
    MIN_DELAY: 8000,        // 最小延迟（毫秒）
    MAX_DELAY: 20000,       // 最大延迟（毫秒）
    BATCH_SIZE: 15,          // 每批数量
    SESSION_TIMEOUT: 300000, // 会话超时
    AUTH_DIR: './auth'       // 认证目录
};
```

## ⚠️ 重要提醒

1. **使用备用账号**：不要用主账号进行检测
2. **不要频繁检测**：遵守延迟和批量限制
3. **分批处理**：将124个号码分8-10天完成
4. **监控账号状态**：检测后观察账号是否正常
