# 排班系统完整 CRUD 交互方案

## 一、社区成熟方案调研

### 1.1 开源排班系统参考

| 项目 | 技术栈 | 特点 | 适用场景 |
|------|--------|------|----------|
| **DHTMLX Scheduler** | React/Vue/Angular | 成熟商业组件，拖拽编辑 | 企业级应用 |
| **FullCalendar** | React/Vue | 开源，轻量级，可定制 | 中小项目 |
| **React Big Calendar** | React | 开源，基于 moment.js | 基础日历功能 |
| **Schedule-X** | React | 现代，TypeScript，事件编辑 | 本项目使用 |

### 1.2 交互设计最佳实践

根据成熟产品（Google Calendar、Outlook、钉钉排班）的经验：

**核心交互原则：**
1. **双视图模式**：日历视图 + 列表视图
2. **拖拽操作**：拖拽调整时间、拖拽换班
3. **快捷操作**：双击编辑、右键菜单、键盘快捷键
4. **批量操作**：批量调整、批量复制、批量删除
5. **撤销重做**：关键操作支持撤销
6. **冲突预警**：实时检测冲突，高亮显示

## 三、详细交互设计

### 3.1 排班计划管理

#### 3.1.1 排班计划列表页

**布局：**
```
┌─────────────────────────────────────────────────────────┐
│  [新建排班] [批量操作] [导出] [设置]                   │
├─────────────────────────────────────────────────────────┤
│  排班计划列表                                            │
│  ┌───────────────────────────────────────────────────┐  │
│  │ [📅] 2026年3月排班  [编辑] [复制] [删除]         │  │
│  │     周期: 2026-03-01 ~ 2026-03-31                │  │
│  │     状态: 已发布 | 员工: 5人 | 班次: 3种         │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ [📅] 2026年4月排班  [编辑] [复制] [删除]         │  │
│  │     周期: 2026-04-01 ~ 2026-04-30                │  │
│  │     状态: 草稿 | 员工: 5人 | 班次: 3种           │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

**操作：**
- 点击「新建排班」→ 打开创建排班对话框
- 点击「编辑」→ 进入排班详情页
- 点击「复制」→ 复制排班计划到新周期
- 点击「删除」→ 确认对话框，删除排班及关联班次

### 3.2 单个班次管理

#### 3.2.1 添加班次

**方式一：日历点击**
- 点击日历空白处 → 弹出新建班次对话框
- 选择日期、班次类型、员工 → 保存

**方式二：快捷菜单**
- 右键日历 → 「添加班次」
- 或按快捷键 `N`

**方式三：拖拽选择**
- 拖拽选择时间范围 → 自动创建班次

#### 3.2.2 编辑班次

**方式一：双击**
- 双击班次 → 弹出编辑对话框

**方式二：右键菜单**
- 右键班次 → 「编辑班次」

**方式三：拖拽**
- 拖拽班次到新时间/日期 → 自动更新
- 拖拽班次到不同员工 → 换班

#### 3.2.3 删除班次

**方式一：右键菜单**
- 右键班次 → 「删除班次」

**方式二：快捷键**
- 选中班次 → 按 `Delete` 或 `Backspace`

**方式三：批量删除**
- 多选班次 → 右键 → 「批量删除」

#### 3.2.4 换班操作

```
换班对话框
┌─────────────────────────────────────┐
│ 🔄 换班                               │
├─────────────────────────────────────┤
│ 当前员工: 张三                         │
│ 当前班次: 早班 2026-03-15            │
│                                     │
│ 换给员工: [下拉选择]                  │
│                                     │
│ [取消]  [确认换班]                    │
└─────────────────────────────────────┘
```

### 3.3 快捷操作

#### 3.3.1 右键菜单

**日历空白处：**
```
┌─────────────────────┐
│ 添加班次    N       │
│ 批量排班...         │
│ 切换视图            │
└─────────────────────┘
```

**班次上：**
```
┌─────────────────────┐
│ 编辑班次    E       │
│ 复制班次    C       │
│ 换班...    S       │
│ 删除班次    Del     │
└─────────────────────┘
```

#### 3.3.2 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `N` | 新建班次 |
| `E` | 编辑选中班次 |
| `C` | 复制选中班次 |
| `V` | 粘贴班次 |
| `Delete` / `Backspace` | 删除选中班次 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Ctrl+S` | 保存 |

## 四、数据流转设计

### 4.1 数据流

```
用户操作
    ↓
UI 组件 (ShiftManager)
    ↓
事件总线 (EventBus)
    ↓
ShiftService
    ↓
IndexedDB (Storage)
    ↓
事件发布 → UI 更新
```

### 4.2 关键事件

```typescript
// 排班计划事件
'shift-schedule:created'
'shift-schedule:updated'
'shift-schedule:deleted'
'shift-schedule:published'

// 班次事件
'shift:created'
'shift:updated'
'shift:deleted'
'shift:moved'
'shift:swapped'

// 批量操作事件
'shifts:batch-updated'
'shifts:batch-deleted'
```
