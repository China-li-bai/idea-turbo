
# 智程日历 - 项目设计文档

**品牌名称**: 智程日历 (SmartCalendar)  
**文档版本**: v1.0  
**最后更新**: 2026-03-16

---

## 📋 项目概述

### 产品定位
智程日历是一款**本地优先的 AI 智能日程管理应用**，专为解决现代职场人士的时间管理痛点而设计。

### 核心价值主张
- **隐私至上**: 数据完全本地存储，永不云端同步
- **AI 赋能**: 自然语言交互，智能日程创建
- **双视图协作**: Boss/秘书视角分离，高效协同
- **灵光捕捉**: 快速记录突发灵感，随时转化

---

## 🎯 核心功能模块

### 1. AI 智能解析 (NLP)
**功能描述**: 
- 支持自然语言输入，如"下周二下午3点见王总"
- 自动解析时间、人物、地点、事件类型
- 一键创建完整日程，无需手动填写多个字段

**设计要点**:
- 简洁的输入界面，支持语音和文字
- 智能推荐地点和联系人
- 实时预览解析结果

---

### 2. Boss/秘书双视图
**功能描述**:
- **Boss 视图**: 简洁显示关键时间节点，屏蔽执行细节
- **秘书视图**: 完整展示准备任务清单、资源关联、进度追踪
- 一键切换视角，数据自动关联

**设计要点**:
- 清晰的角色标识和切换控件
- Boss 视图聚焦时间线，秘书视图聚焦任务清单
- 任务完成状态可视化

---

### 3. 灵光时刻捕获
**功能描述**:
- 浮动按钮快速入口，随时记录突发想法
- 支持文字、语音、截图多种输入方式
- AI 智能分类（待办/日程/笔记/灵感）
- 收集箱管理，支持批量处理

**设计要点**:
- 明显的悬浮按钮，不干扰主界面
- 极简输入界面，降低使用门槛
- 收集箱采用卡片式布局，易于处理

---

### 4. 智能排班系统
**功能描述**:
- 支持餐饮业、零售业、医疗业等多行业排班
- AI 智能生成班表，满足公平性和约束条件
- 拖拽调整，可视化编辑
- Excel 导出，分享链接

**设计要点**:
- 直观的日历视图展示班表
- 员工偏好和约束设置面板
- 一键生成，一键导出

---

### 5. 本地优先 · 隐私至上
**功能描述**:
- 所有数据存储在本地 IndexedDB
- 使用 EdgeVec (WASM) 做本地向量搜索
- Transformers.js + WebGPU 做本地 Embedding
- 混合 AI 模式：简单任务本地处理，复杂任务可选 API

**设计要点**:
- 强调"本地"、"隐私"的视觉元素
- 数据加密指示器
- AI 模式选择界面

---

### 6. 智能冲突检测
**功能描述**:
- 实时监测日程时间重叠
- 优雅提示冲突并提供解决方案
- 智能建议调整时间

**设计要点**:
- 冲突日程高亮显示
- 友好的提示弹窗
- 快捷调整按钮

---

### 7. 多语言 · 跨时区
**功能描述**:
- 智能识别系统语言
- 支持简体中文、繁体中文、英文、日文、韩文
- 自动时区适配

**设计要点**:
- 语言切换控件
- 时区设置界面

## 🎯 目标用户画像

### 1. 企业高管 (Boss)
- **痛点**: 日程繁杂，信息过载
- **需求**: 简洁视图，快速获取关键时间
- **使用场景**: 日常查看、会议确认

### 2. 行政秘书/助理
- **痛点**: 需要处理大量准备工作，任务分散
- **需求**: 完整任务清单，进度追踪
- **使用场景**: 日程安排、任务管理、资源协调

### 3. 自由职业者/创业者
- **痛点**: 时间管理混乱，隐私担忧
- **需求**: 本地存储，AI 辅助
- **使用场景**: 日程规划、灵感记录

### 4. 排班管理员
- **痛点**: 手动排班效率低，公平性难保证
- **需求**: AI 智能排班，拖拽调整
- **使用场景**: 班表生成、员工管理

## 🚀 技术架构

### 前端技术栈
- **框架**: Next.js 16 + React 19
- **状态管理**: Zustand
- **本地存储**: localforage (IndexedDB)
- **向量搜索**: Orama + EdgeVec
- **AI 能力**: Transformers.js + WebGPU
- **日历 UI**: Schedule-X
- **样式**: SCSS Modules

### 数据流向
```
用户输入 → 本地 NLP 解析 → 本地存储 → UI 更新
                ↓
            可选 API 增强
```

## 💡 设计原则

### 1. 极简至上
- 减少认知负担
- 核心功能一目了然
- 隐藏复杂操作

### 2. 本地优先
- 强调隐私和安全
- 突出本地处理能力
- 网络不是必需

### 3. AI 赋能
- AI 是助手，不是主角
- 智能推荐，不强制
- 保留人工控制权

### 4. 响应式设计
- 桌面优先，兼顾平板
- 自适应布局
- 流畅的交互体验
