# P2P 用户列表同步改进

## 问题描述
在纯 P2P 服务测试中，每个用户无法看到完整的在线用户列表，因为在 P2P 网络中，每个节点只能直接知道与之连接的其他节点。

## 解决方案
1. 在 P2PRoomService 中添加了用户列表广播机制
2. 当用户加入或离开时，广播完整的用户列表给所有已连接的节点
3. 添加了 `peer-list` 消息类型，用于传输用户列表
4. 在 UI 中添加了手动刷新用户列表的功能

## 主要更改

### P2PRoomService.ts
1. 添加了 `broadcastPeerList` 方法，用于广播完整的用户列表
2. 修改了 `addPeer` 和 `removePeer` 方法，在用户状态变化时广播更新
3. 添加了 `requestPeerListSync` 公共方法，允许手动触发用户列表同步
4. 更新了 `handleSignalingMessage` 方法，处理 `peer-list` 消息类型

### PureP2PTest.tsx
1. 添加了 `getAllPeers` 函数，用于获取排序后的用户列表
2. 更新了用户列表 UI，使用新的排序逻辑
3. 添加了 `refreshPeerList` 函数，允许手动刷新用户列表
4. 在用户列表区域添加了刷新按钮

## 使用方法
1. 创建或加入房间后，每个用户会自动同步用户列表
2. 如果发现用户列表不一致，可以点击"刷新"按钮手动同步
3. 用户列表按以下规则排序：
   - 当前用户排在第一位
   - 按连接状态排序：已连接 > 连接中 > 已断开
   - 最后按用户ID排序

## 测试建议
1. 打开多个浏览器窗口或标签页
2. 使用相同的房间ID加入房间
3. 观察用户列表是否正确显示所有在线用户
4. 测试用户加入/离开时列表是否实时更新
5. 测试手动刷新功能是否正常工作
