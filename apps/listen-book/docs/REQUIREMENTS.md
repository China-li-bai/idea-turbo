# 语言学习应用需求文档

## 1. 项目概述

### 1.1 项目背景

基于第二语言习得（Second Language Acquisition，SLA）理论，构建一个符合语言学习自然规律的应用程序。该应用将遵循科学的语言学习阶段划分，采用经过验证的教学方法，帮助学习者高效掌握目标语言。

### 1.2 目标用户

- 零基础语言学习者
- 有一定基础希望系统提升的学习者
- 需要灵活学习时间安排的职场人士
- 偏好自主学习的学习者

### 1.3 核心价值

- **科学性**：基于 SLA 理论和研究成果
- **高效性**：遵循 i+1 可理解性输入原则
- **个性化**：根据学习者水平动态调整难度
- **灵活性**：支持碎片化学习，适应不同场景

## 2. 理论基础

### 2.1 语言学习四阶段理论

| 阶段 | 名称 | 时长 | 目标 | 核心方法 |
|--------|------|------|------|----------|
| 第一阶段 | 早期（Early Stage） | 1-2 个月 | 掌握约 1000 个"声音" | 看图识音、TPR |
| 第二阶段 | 提高期（Upping the Ante） | 2-3 个月 | 听懂简单句子和段落 | 续列法、生成对话 |
| 第三阶段 | 增长期（Getting Serious） | 3-6 个月 | 提高流利度，开始输出 | 窄输入、间隔重复 |
| 第四阶段 | 高级期（Scaling Everest） | 持续 | 接近母语水平 | 广泛阅读、深度交流 |

### 2.2 核心理论支持

#### 2.2.1 可理解性输入 i+1 (Comprehensible Input)

**理论来源**：Stephen Krashen 的输入假说（Input Hypothesis）

**核心观点**：
- 语言习得主要通过理解性输入实现
- 输入难度应略高于当前水平（i+1）
- 过难或过易的输入都无效

**应用原则**：
- 新内容占比控制在 10%-20%
- 第一遍听懂率应达到 80%-90%
- 80 分万岁，不要追求 100 分

#### 2.2.2 TPR 全身反应法 (Total Physical Response)

**理论来源**：James Asher (1960s)

**核心观点**：
- 通过身体动作建立语言与行为的联系
- 左右脑协调训练建立语言思维
- 降低学习焦虑，符合 SLA 理念

**应用原则**：
- 听指令做反应，不强迫开口
- 先建立听力能力，再考虑输出
- 可扩展为 TPR-B/O/P/S 变种

#### 2.2.3 窄输入 (Narrow Input)

**核心观点**：
- 集中学习特定主题或场景
- 通过重复和关联提高理解
- 逐步扩展到其他领域

**应用场景**：
- 续列法：生活场景连续动作
- 生成对话：基于熟悉背景的对话
- 故事系列：连续情节的叙事

#### 2.2.4 情感过滤 (Affective Filter)

**核心观点**：
- 焦虑会阻碍语言习得
- 降低情感过滤可以提高学习效率
- 多媒体学习焦虑度较低

**应用原则**：
- 避免纠错和压力
- 提供积极反馈
- 允许犯错和猜测

#### 2.2.5 间隔重复 (Spaced Repetition)

**理论来源**：遗忘曲线（Ebbinghaus Forgetting Curve）

**核心观点**：
- 遗忘遵循特定规律
- 在特定时间点复习可显著提高记忆
- 系统化的复习计划至关重要

**应用原则**：
- 使用 FSRS 等先进算法
- 根据个人表现动态调整
- 支持自定义复习计划

#### 2.2.6 CALL 计算机辅助语言学习

**理论来源**：国际 CALL 协会研究

**核心观点**：
- 多媒体可模拟真实场景
- 技术可实现比真人更科学的条件
- 降低焦虑，提高效率

**最佳实践**：
- 画面静止，降低视觉注意力
- 画面简单，信息量少
- 故事连续，情节相关
- 声音与画面配合，支持预测

## 4. 日常外语日记模块（核心创新功能）

### 4.1 模块概述

**模块名称**：日常外语日记（Daily Foreign Language Journal）

**设计理念**：
将语言学习融入日常生活，通过记录和翻译自己的故事，实现 100% 可理解性的沉浸式学习。

**核心理念**：
```
用户中文输入 → AI翻译 → 语音合成 → 听读学习
     ↓
  生活场景（熟悉）→ 情感连接（感恩）→ 主动学习（自己的故事）
```

**理论支撑**：
- **窄输入**：记录自己的生活场景，内容高度相关
- **可理解性 100%**：自己写的内容，背景全懂
- **情感过滤**：感恩日记，正向情绪，降低焦虑
- **多模态学习**：听+读，左右脑协同

### 4.2 用户故事

#### 4.2.1 核心用户故事

> 作为一名希望提高外语水平的学习者，我希望能用母语记录每天的感悟和感恩的事情，然后翻译成目标语言进行学习，这样我学习的内容都是我自己熟悉的、感兴趣的，记忆效果更好。

#### 4.2.2 子用户故事

| 角色 | 需求 | 场景 |
|------|------|------|
| 职场人士 | 碎片化学习 | 通勤路上用 5 分钟学习昨日日记 |
| 学生 | 巩固语法 | 睡前复习当天学习内容 |
| 旅行者 | 场景化学习 | 记录旅行见闻，学习相关表达 |
| 家长 | 亲子学习 | 和孩子一起记录，陪伴成长 |

```typescript
interface JournalEntry {
  id: string;
  userId: string;
  date: Date;
  originalText: string;
  originalLanguage: string;
  translations: Translation[];
  audioUrls: Record<string, string>; // language -> audioUrl

  template: string;
  createdAt: Date;
  updatedAt: Date;

interface Translation {
  language: string;
  text: string;
  difficulty: 'simple' | 'medium' | 'advanced';
  newVocabularies: Vocabulary[];
}

interface Vocabulary {
  word: string;
  translation: string;
  context: string;
  audioUrl?: string;
}
```
