# 持久化数据结构与数据流分析

## 持久化数据总览

```
┌─────────────────────────────────────────────────────────────┐
│  Yjs 文档（多设备同步 + IndexedDB 持久化）                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  ytext: Y.Text                                      │   │
│  │    └─ content: string  (原始文本)                   │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  yplaybackState: Y.Map                             │   │
│  │    ├─ currentSegmentId: number  (当前播放位置)      │   │
│  │    ├─ isPlaying: boolean      (是否正在播放)        │   │
│  │    ├─ isPaused: boolean       (是否暂停)             │   │
│  │    └─ updatedAt: number       (更新时间戳)           │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 数据结构详解

### 1. Yjs 文档结构

```typescript
// Yjs 文档结构
{
  // 1. 原始文本（Y.Text 类型）
  ytext: Y.Text {
    content: string  // 用户输入的原始文本
  },
  
  // 2. 播放状态（Y.Map 类型）
  playbackState: Y.Map {
    currentSegmentId: number,  // 当前播放的段落 ID
    isPlaying: boolean,        // 是否正在播放
    isPaused: boolean,         // 是否暂停
    updatedAt: number           // 最后更新时间戳
  }
}
```

### 2. 内存数据结构（不持久化）

```typescript
// React State
{
  rawText: string,              // 原始文本（从 ytext 同步）
  segments: TextSegment[],      // 分段数据（仅内存）
  paragraphs: TextParagraph[],  // 段落数据（仅内存）
  currentSegmentId: number,     // 当前播放位置（从 playbackState 同步）
  isProcessing: boolean,        // 是否正在处理
  error: string | null,         // 错误信息
  syncStatus: 'synced' | 'syncing' | 'offline'  // 同步状态
}

// PlaybackController 内部状态
{
  segments: TextSegment[],      // 分段数据
  paragraphs: TextParagraph[],  // 段落数据
  state: PlaybackState {
    isPlaying: boolean,
    isPaused: boolean,
    currentSegmentId: number,
    currentParagraphId: number,
    playbackProgress: number,
    speed: number,
    volume: number,
    voice: SpeechSynthesisVoice | null,
    error: PlaybackError | null,
    startTime: number,
    pausedAt: number
  }
}
```

## 数据流分析

### 数据流图

```
┌─────────────────────────────────────────────────────────────┐
│  用户输入文本                                                  │
│    ↓                                                          │
│  setText(text)                                                │
│    ↓                                                          │
│  ytext.insert(0, text)  ──→  Yjs 更新  ──→  IndexedDB 存储  │
│    ↓                                                          │
│  ytext.observe 触发                                          │
│    ↓                                                          │
│  processor.process(text)  ──→  生成 segments/paragraphs       │
│    ↓                                                          │
│  setSegments, setParagraphs  ──→  更新 React State           │
│    ↓                                                          │
│  playbackRef.setContent  ──→  更新 PlaybackController         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  播放事件                                                      │
│    ↓                                                          │
│  PlaybackController.emit('segmentStart')                      │
│    ↓                                                          │
│  setCurrentSegmentId(segment.id)  ──→  更新 React State       │
│    ↓                                                          │
│  yplaybackState.set('currentSegmentId', segment.id)          │
│    ↓                                                          │
│  Yjs 更新  ──→  IndexedDB 存储  ──→  多设备同步               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  刷新页面                                                      │
│    ↓                                                          │
│  IndexeddbPersistence 初始化                                   │
│    ↓                                                          │
│  IndexedDB 加载数据到 Yjs 文档                                 │
│    ↓                                                          │
│  synced 事件触发                                               │
│    ↓                                                          │
│  ytext.toString()  ──→  获取保存的文本                       │
│    ↓                                                          │
│  processor.process(savedText)  ──→  重新生成 segments       │
│    ↓                                                          │
│  playbackRef.restoreState(savedSegmentId)  ──→  恢复播放位置  │
└─────────────────────────────────────────────────────────────┘
```

## Linus 风格评价

### Taste Rating: 🟢 Good Taste

### 优点

1. **数据结构正确**
   ```
   ✅ segments/paragraphs 不持久化
   
   这是正确的选择：
   - segments 是从 rawText 派生的数据
   - 可以随时重新生成
   - 不需要存储，避免冗余
   - 避免序列化问题（之前的栈溢出）
   ```

2. **数据流清晰**
   ```
   ✅ 单向数据流
   
   用户输入 → Yjs → IndexedDB
   Yjs → React State → UI
   PlaybackController → Yjs → IndexedDB
   
   没有循环依赖，没有特殊分支。
   ```

3. **职责分离**
   ```
   ✅ 每个组件职责明确
   
   - Yjs: 数据同步和持久化
   - IndexedDB: 本地存储
   - React State: UI 状态
   - PlaybackController: 播放逻辑
   - TextProcessor: 文本处理
   ```

4. **事件驱动**
   ```
   ✅ 解耦良好
   
   PlaybackController 通过事件通知 UI
   UI 通过事件更新 Yjs
   没有直接依赖，易于测试和维护
   ```

### 改进建议

1. **添加数据版本控制**
   ```typescript
   // 建议在 playbackState 中添加版本号
   playbackState: Y.Map {
     version: number,  // 数据版本号
     currentSegmentId: number,
     isPlaying: boolean,
     isPaused: boolean,
     updatedAt: number
   }
   
   用途：
   - 检测数据冲突
   - 处理多设备并发更新
   - 避免数据覆盖
   ```

2. **添加数据迁移逻辑**
   ```typescript
   // 建议在 synced 事件中添加版本检查
   idbPersistence.current.on('synced', () => {
     const version = yplaybackState.get('version') as number | undefined;
     
     if (version === undefined || version < CURRENT_VERSION) {
       // 执行数据迁移
       migrateData(version);
     }
   });
   
   用途：
   - 处理旧版本数据
   - 避免兼容性问题
   ```

3. **优化 observeText 防抖**
   ```typescript
   // 建议添加防抖，避免频繁处理
   const observeTextDebounced = useMemo(
     () => debounce(observeText, 300),
     []
   );
   
   ytext.observe(observeTextDebounced);
   
   用途：
   - 减少不必要的处理
   - 提高性能
   ```

## 核心判断

```
✅ 数据结构正确，数据流清晰

持久化数据：
- rawText: ✅ 必须持久化（用户输入）
- currentSegmentId: ✅ 必须持久化（播放位置）
- isPlaying/isPaused: ✅ 可选持久化（播放状态）
- segments/paragraphs: ✅ 不持久化（派生数据）

数据流：
- 用户输入 → Yjs → IndexedDB ✅
- 播放事件 → Yjs → IndexedDB ✅
- 刷新恢复 → IndexedDB → Yjs → 内存 ✅

没有循环，没有冗余，没有特殊分支。
这是 Good Taste 的代码。
```

## 总结

**当前持久化数据**：
1. ✅ `rawText` - 原始文本（Y.Text）
2. ✅ `currentSegmentId` - 当前播放位置（Y.Map）
3. ✅ `isPlaying` - 播放状态（Y.Map）
4. ✅ `isPaused` - 暂停状态（Y.Map）
5. ✅ `updatedAt` - 更新时间（Y.Map）

**不持久化数据**：
1. ✅ `segments` - 分段数据（内存）

**数据流评价**：
- 🟢 清晰：单向数据流，无循环依赖
- 🟢 正确：派生数据不持久化
